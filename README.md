# 图书爬虫与AI文档检索项目
## 项目简介
基于Python requests实现网页数据爬取，结合大模型API构建简易RAG文档检索应用，完成网页数据采集、数据清洗、文本向量化、知识库问答整套流程。

## 技术栈
Python、requests、lxml、文件读写、大模型API、文本处理

## 项目功能
1. 爬虫模块：请求目标网页，处理编码乱码，提取页面文本信息，过滤空白字符，将采集结果持久化保存到本地文件，增加异常捕获处理网络请求错误。
2. AI应用模块：读取本地文档，完成文本分段处理，调用大模型接口实现知识库问答，基于已有文档内容回答用户提问。

## 项目收获
熟悉HTTP请求流程，掌握网页数据解析、文件存储；理解RAG基础工作流程，能够调用大模型API开发简单AI应用，具备数据采集‑AI应用落地的开发能力。
